# 벌레 퇴치녀 — Claude Code 전달용 요약

이 폴더(stage1_assets)는 웹게임 "벌레 퇴치녀"의 **1구간(1~10스테이지) 그림 에셋 전부**다. 파일 규격·사용법은 `README.md`를 먼저 읽는다. 이 문서는 게임 규칙 요약이다. HTML/CSS/JS(Canvas)로 만들고 GitHub에 올린다. 혼자 만드는 프로젝트라 단순하고 읽기 쉬운 구조를 원한다.

## 게임 개요
- 웨이브 생존 액션. 총 100스테이지.
- 구간 = ceil(stage/10). 구간이 바뀔 때마다 잡몹·보스·배경이 바뀐다.
- 10스테이지마다 보스(stage % 10 == 0). 1구간 보스 = 벌레왕(boss_bee).
- 5스테이지마다 버프 선택(stage % 5 == 0). 총 20번. 3개 중 1개를 고른다.
- 아이템 드랍(하트 회복) 확률 = 목표 기대치 1.5 / 그 스테이지 몹 수.
- 크기 규격: 플레이어 64px, 잡몹 60px, 보스 160px. 모든 캐릭터는 오른쪽을 보며, 왼쪽은 좌우 반전만 쓴다(4방향 없음).
- 8~10스테이지는 같은 몹의 색 변형(`_alt`) 강화 개체를 쓴다(동작은 그대로).
- 피격 흰색 번쩍임, 사망 페이드아웃은 코드에서 처리한다(그림 없음).

## 무기·버프 시스템
- 시작 무기는 칼(sword) 하나. 칼 공격 효과는 `effects/slash_1~3.png`.
- 버프 선택지는 무기다. 이미 가진 무기를 또 고르면 **강화**(데미지·범위·속도 등 수치 증가), 새 무기를 고르면 **추가**. 무기는 중첩 보유 가능.
- 강화는 새 그림 없이 코드에서 크기·수치를 키운다. 레벨 표시·카드 틀·글자는 코드/CSS로 그린다.
- 무기 아이콘 id는 `weapons/icons.json`, 공격 효과는 `weapons/fx/weapon_fx.json`.

능력 강화 아이콘(stat_damage, stat_range, stat_speed)은 강화 카드에서 어떤 수치가 오르는지 보여 주는 용도.

## 1구간 몹
- ant(돌진형), ladybug(탱커형), fly(원거리형, 침 투사체), boss_bee(벌레왕, 근접 돌진). 스테이지별 등장 구성·체력·속도는 아직 정하지 않았으니 구현하면서 제안해 달라.

## 아직 없는 것 (코드로 만들거나 나중에 추가)
- 체력 UI는 하트 이미지(effects/heart_1~2.png)로 대체하거나 코드로 그린다. 버프 카드 틀·버튼·타이틀 화면은 CSS/코드.
- 2~10구간 몹·보스·배경 타일은 아직 없다(구간 구조를 데이터로 빼 두면 나중에 그림만 추가하면 된다).
- 사운드 없음.
- 주인공 그림은 임시 디자인이다(나중에 같은 규격으로 교체 예정이니 `player` 폴더 파일만 바꾸면 되게 만들어 달라).
- 프레임 정보(크기·피벗·fps)는 하드코딩하지 말고 각 json에서 읽는다.
