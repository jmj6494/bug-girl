# 벌레 퇴치녀

버프를 골라 성장하는 스테이지형 웹게임입니다. **지금 개발 중입니다.**

골드도 경험치도 없습니다. 5스테이지마다 나오는 버프 카드 3장 중 1장을 고르는 것만으로 강해집니다.
무엇을 고르느냐에 따라 같은 스테이지도 다르게 풀립니다.

---

## 지금 상태

- 1구간(1~10스테이지)까지 돌아갑니다. 10스테이지는 보스(벌) 스테이지입니다
- 2구간(11~20스테이지, 동굴)은 작업 중입니다

## 만든 방식

학교 동아리 프로젝트입니다. 3명 팀이고 제가 조장입니다.

**AI 협업 코딩(바이브 코딩)으로 만들고 있습니다.** 코드는 AI와 같이 쓰고, 기획과 밸런스 조정은 제가 합니다.

캐릭터와 몹 그림도 AI로 만들었습니다. 그런데 그릴 때마다 크기나 모양이 조금씩 달라졌습니다.
그래서 캐릭터 크기, 동작별 프레임 수, 배경 투명 같은 규칙을 정리한 규격서를 파일로 만들어 두고, 그림을 시킬 때마다 같이 보냅니다.

## 해보기

`game/index.html`을 브라우저로 열면 바로 실행됩니다. 따로 설치할 건 없습니다.

| 키 | 하는 일 |
|---|---|
| WASD / 방향키 | 이동 |
| (자동) | 공격 |
| P / Esc | 일시정지 |
| 1 · 2 · 3 또는 클릭 | 버프 카드 고르기 |

## 기술

JavaScript · HTML · CSS (Canvas로 화면을 그립니다)

밸런스 숫자(몹 체력, 무기 수치, 스테이지 구성)는 `game/js/data.js` 한 파일에 모아 두었습니다.
숫자를 고칠 때 이 파일만 보면 됩니다.

## 폴더

```
game/            게임 본체 (자세한 설명은 game/README.md)
  js/data.js     밸런스 숫자와 스테이지 구성
  assets/        캐릭터·몹·무기·바닥 그림
디자인_구버전/      처음 디자인 시안
디자인_현제 버전/    지금 쓰는 디자인 시안
```
